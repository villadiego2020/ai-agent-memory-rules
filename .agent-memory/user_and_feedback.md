# User and Project Rules

> Record durable, non-secret project guidance only. This file is versioned with the project and may become model-visible context.

- Maintain both Codex and Claude global agent configurations for personal, cross-project use on this machine.
- Do not copy configuration into or push changes to other project repositories without an explicit request.
- Prefer direct execution for small, low-risk work; delegate and test in proportion to actual risk.
- Keep shared game-development guidance on demand; improve UX fidelity, proportionate architecture, networking analysis, and understandable test evidence.
- Generalize lessons from external repositories without importing private project code, history, or Memory.
